# AWS Bedrock AgentCore Customer Service Agent

An AI-powered customer service agent built and deployed using Amazon Bedrock AgentCore as part of an AWS hands-on workshop.

## Project Overview

This project demonstrates how AI agents can support customer service operations by retrieving order information, answering customer questions, and managing conversations.

## Features

- Customer identification and order retrieval
- Order status and delivery tracking
- Custom customer service tools
- Agent hooks and request handling
- Skills-based workflow management
- Session management for conversations
- Cloud deployment using Amazon Bedrock AgentCore Runtime

## Technologies Used

- Python
- Amazon Bedrock
- Amazon Bedrock AgentCore
- AWS IAM
- AWS CloudFormation
- Strands Agents SDK
- Git and GitHub

## Project Implementation

The project was completed through five AWS workshop modules:

1. Agent Loop and Tools
2. Hooks
3. Skills and Steering
4. Session Managers
5. Deployment to AgentCore Runtime

## Testing

The agent was successfully deployed to AWS and tested using the AgentCore CLI.

During testing, the agent retrieved customer order details, including order IDs, prices, shipping statuses, and delivery information.

## Learning Outcomes

This project provided hands-on experience with AI agent development, AWS cloud services, Python-based automation, cloud deployment, and agent testing.
